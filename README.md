# Migration Counseling Bot

A Telegram bot that works as an LLM-powered consultation assistant for migration questions.

> The source code of this project is private. This page describes what it does and how it is run. I am happy to walk through the design in an interview.

## What it does
- Answers users' migration-related questions in a Telegram chat, powered by a large language model.
- Keeps its data in databases and runs recurring work as scheduled tasks.

## How it is run
- Runs as its own service on a Linux server.
- Has defined maintenance procedures (a runbook) so someone else can operate it.
- Delivered and handed over with project documentation.

## Context
Built at Arika (2024 - 2026) as one of five production services I delivered and handed over.
